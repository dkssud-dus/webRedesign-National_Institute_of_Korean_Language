## 1. Project Overview
### 1.1. Background  
The National Institute of Korean Language is a public institution that systematically establishes policies and conducts research for the development of the Korean language and smooth communication among the people. According to the institution's purpose, anyone who uses Korean should be able to access information easily and quickly. However, the existing website lacked information hierarchy and emphasis on the main page, making it difficult for users to identify their destination or find the information they needed. Additionally, the main visual had minimal presence, which I thought did not properly reflect the image of the National Institute of Korean Language as a public institution. Therefore, this project aimed to enhance user accessibility and participation while conveying the trustworthiness of a public institution by improving the main visual and information arrangement.

</br>

The objectives of this project are as follows:

</br>

1. To more clearly convey the role and brand image of the National Institute of Korean Language.
2. To improve accessibility and usability so that all Korean language users can easily and quickly access information.
3. To develop the website beyond information provision into one where users can actively participate and communicate.

</br>
</br>
</br>

### 1.2. Keywords
1. **Easier**   
  1.1. Arranged broadly and cleanly to enable information confirmation at a glance
  1.2. UI/UX designed to help users access and utilize information

</br>

2. **Trustworthy**      
  2.1. Emphasizing main visual and information hierarchy to convey brand authority and trustworthiness

</br>

3. **Participation-oriented**   
  3.1. Including interactions and events to enable active user participation beyond information provision


</br>
</br>
