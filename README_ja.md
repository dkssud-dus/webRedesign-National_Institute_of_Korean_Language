## 1. プロジェクト概要
### 1.1. 背景  
国立国語院は国語の発展と国民の円滑なコミュニケーションのために体系的に政策を立て、研究を行う公共機関である。機関の目的によれば、日本語を使用する誰もが簡単かつ迅速に情報にアクセスできるべきである。しかし既存のウェブサイトはメインページで情報の階層と強調が不足しており、ユーザーが目的地を確認したり希望する情報を見つけ出すことが困難であった。またメインビジュアルの存在感も微々たるもので、国立国語院という公共機関のイメージが適切に現れていないと思われた。そこでこのプロジェクトでは、メインビジュアルと情報の配列を改善することで、公共機関の信頼感を伝えると同時にユーザーのアクセシビリティと参加を一層強化しようとした。

</br>

このプロジェクトの目的は次の通りである。

</br>

1. 国立国語院という機関の役割とブランドイメージをより鮮明に伝えようとする。
2. 日本語使用者全員が簡単かつ迅速に情報を確認できるようアクセシビリティと使いやすさを改善する。
3. 情報提供を超えてユーザーが積極的に参加しながらコミュニケーションできるウェブサイトに発展させる。

</br>
</br>
</br>

### 1.2. キーワード
1. **より簡単な**   
  1.1. 広くきれいに配列されて一目で情報を確認可能にするように
  1.2. ユーザーの情報アクセスと活用を助けるようUI/UXを設計 

</br>

2. **信頼できる**      
  2.1. ブランドの権威と信頼感を伝えるためにメインビジュアルと情報階層を強調

</br>

3. **参加指向**   
  3.1. 情報提供を超えてユーザーが積極的に参加できるようインタラクションとイベントを含む


</br>
</br>
</br>
