# 국립국어원
![Animation2](https://github.com/user-attachments/assets/9710ba81-118f-4239-8618-37ca705d1c80)

<br/><br/>

**공공기관의 신뢰감과 접근성을 높이기 위해 재설계한 국립국어원 웹 사이트**
> 해당 프로젝트는 국립국어원의 정보 전달성과 접근성을 개선하기 위해 진행한 개인 리디자인입니다. 메인 페이지를 중심으로 주요 서비스를 직관적으로 배치해 이용자가 필요한 정보를 빠르게 찾을 수 있게 구성했습니다. 또한 스와이퍼·섹션 앵커·사이드 퀵 메뉴 등 인터랙션을 통해 탐색 편의성을 높였고, 영어·일본어용 메인 페이지도 별도로 구성해 다국어 접근성을 고려했습니다. 결과적으로 공공기관으로서의 신뢰감과 사용성 두 가지를 모두 개선하는 것을 목표로 했습니다.

## Overview
### Background
국립국어원은 국어의 발전과 국민의 원만한 소통을 위해 체계적으로 정책을 수립하고 연구를 수행하는 공공기관이다. 기관 목적에 따르면, 한국어를 사용하는 누구나 쉽고 빠르게 정보에 접근할 수 있어야 한다. 그러나 기존 웹사이트는 메인 페이지에서 정보의 계층과 강조가 부족해 사용자가 목적지를 확인하거나 원하는 정보를 찾아내기가 어려웠다. 또한 메인비주얼의 존재감도 미미해 국립국어원이라는 공공기관의 이미지를 제대로 드러나지 않는다고 생각됐다. 이에 이 프로젝트에서는 메인 비주얼과 정보의 배열을 개선함으로써 공공기관의 신뢰감을 전달하면서 동시에 사용자의 접근성과 참여를 한층 강화하고자 하였다.

<br/>

### Purpose
- 국립국어원이라는 기관의 역할과 브랜드 이미지를 더욱 선명하게 전달하고자 한다.
- 한국어 사용자 모두가 쉽고 빠르게 정보를 확인할 수 있도록 접근성과 사용성을 개선한다.
- 정보 제공을 넘어 사용자가 적극적으로 참여하면서 소통할 수 있는 웹사이트로 발전시킨다.
  
<br/>

### Keywords
`보다 쉬운`
- 넓고 깔끔하게 배열되어 한눈에 정보를 확인 가능하도록
- 사용자의 정보 접근과 활용을 돕도록 UI/UX를 설계 
  
`신뢰 가는`
- 브랜드의 권위과 신뢰감을 전달하기 위해 메인 비주얼과 정보 계층을 강조

`참여 지향`
- 정보 제공을 넘어 사용자가 적극적으로 참여할 수 있도록 인터랙션과 이벤트를 포함

### Header + Navigation
**Summary**
- 헤더의 색상은 호버와 스크롤시 변경되도록 하여 사용자가 언제든지 필요한 정보의 카테고리로 넘어갈 수 있도록 하였다.
- 좌측의 글로벌 버튼을 클릭하면 언어 변경이 가능해, 영어와 일본어 페이지에 접근이 가능하다.
- 반응형에서 내비게이션은 세 줄의 햄버거 버튼으로 변경되며, 클릭시 화면을 가득 채우는 아코디언 메뉴가 등장하도록 하였다.

### Section Anchor
**Summary**
- 국립국어원 페이지인만큼, 한글 자음을 아이콘처럼 사용하고자 디자인된 영역이다.
- 호버시 섹션의 이름이 등장하여 어느 부분으로 이동할 수 있는지 사용자에게 알려줄 수 있도록 하였다.
- 스크롤시 국립국어원의 메인 컬러로 변경되어 가시성을 높이고자 하였다.

### 빠른 이동
**Summary**
- 기존 웹사이트에서도 강조했던 국어 상담과 언어 개선 파트를 오른쪽에 사이드 메뉴 형태로 만들어 메인 페이지의 어느 영역을 보고 있더라도 바로 이동 가능토록 하였다.
- 호버시 왼쪽으로 늘어나며 각 아이콘에 맞는 제목이 드러나며, 영역에 호버할 경우에는 글씨의 색상이 변경된다.

### 함께하는 우리말 다듬기
**Summary**
- 다듬은 말 영역은 독립적인 영역으로 재구성하여, 지금까지 국립국어원이 다듬은 말이 몇 개인지 알 수 있도록 좌측에 수치로 배치하였다.
- 우측의 토글 버튼 클릭시, 다듬기 전 단어에서 다듬은 후 단어로 변경되며 단어가 어떻게 우리말로 다듬어지게 되었는지 사용자가 클릭으로 직접 확인해 볼 수 있도록 하였다.

- 데스크탑 버전에서는 세 개의 카드를 볼 수 있으며, 태블릿 버전에서는 두 개, 모바일 버전에서는 한 개의 카드를 볼 수 있도록 하였다.

### 국립국어원 누리 소통망 바로가기
**Summary**
- 기존에 없던 SNS 소식 영역을 추가함으로써 국립국어원의 활동이나 이벤트를 홍보하고자 하였다.
- 좌측에 스와이퍼를 사용하여 소식을 보여주고, 우측에는 각 SNS 아이콘을 배치하여 공식 페이지를 바로갈 수 있도록 디자인하였다.
- SNS 아이콘은 호버시 좌측으로 늘어나며 "해당 SNS 이름" 바로가기, 라는 텍스트가 등장하도록 하였다.
- 스와이퍼 내부 카드는 모바일 버전에서 두 개씩 배치되었다.

### Korea.net
