## 1. 프로젝트 개요

### 1.1. 작업 배경
국립국어원은 국어의 발전과 국민의 원만한 소통을 위해 체계적으로 정책을 수립하고 연구를 수행하는 공공기관이다. 기관 목적에 따르면, 한국어를 사용하는 누구나 쉽고 빠르게 정보에 접근할 수 있어야 한다. 그러나 기존 웹사이트는 메인 페이지에서 정보의 계층과 강조가 부족해 사용자가 목적지를 확인하거나 원하는 정보를 찾아내기가 어려웠다. 또한 메인비주얼의 존재감도 미미해 국립국어원이라는 공공기관의 이미지를 제대로 드러나지 않는다고 생각됐다. 이에 이 프로젝트에서는 메인 비주얼과 정보의 배열을 개선함으로써 공공기관의 신뢰감을 전달하면서 동시에 사용자의 접근성과 참여를 한층 강화하고자 하였다.

</br>

이 프로젝트의 목적은 다음과 같다.

</br>

1. 국립국어원이라는 기관의 역할과 브랜드 이미지를 더욱 선명하게 전달하고자 한다.
2. 한국어 사용자 모두가 쉽고 빠르게 정보를 확인할 수 있도록 접근성과 사용성을 개선한다.
3. 정보 제공을 넘어 사용자가 적극적으로 참여하면서 소통할 수 있는 웹사이트로 발전시킨다.

</br>
</br>
</br>

### 1.2. 키워드

1. **보다 쉬운**   
  1.1. 넓고 깔끔하게 배열되어 한눈에 정보를 확인 가능하도록
  1.2. 사용자의 정보 접근과 활용을 돕도록 UI/UX를 설계 

</br>

2. **신뢰 가는**      
  2.1. 브랜드의 권위과 신뢰감을 전달하기 위해 메인 비주얼과 정보 계층을 강조

</br>

3. **참여 지향**   
  3.1. 정보 제공을 넘어 사용자가 적극적으로 참여할 수 있도록 인터랙션과 이벤트를 포함

## 3. 주요 기능 소개

#### 3.1.1. 한국어 페이지
1. 메인 페이지는 한국어로 작업하였으며, 내비게이션 좌측에 배치된 글로벌 버튼을 클릭하면 영어와 일본어 페이지로 이동 가능하게 설계되었다.
2. 이하의 설명은 한국어 페이지를 기준으로 한다.

1. 헤더의 색상은 호버와 스크롤시 변경되도록 하여 사용자가 언제든지 필요한 정보의 카테고리로 넘어갈 수 있도록 하였다.
2. 좌측의 글로벌 버튼을 클릭하면 언어 변경이 가능해, 영어와 일본어 페이지에 접근이 가능하다.
3. 반응형에서 내비게이션은 세 줄의 햄버거 버튼으로 변경되며, 클릭시 화면을 가득 채우는 아코디언 메뉴가 등장하도록 하였다.

2. 호버시 섹션의 이름이 등장하여 어느 부분으로 이동할 수 있는지 사용자에게 알려줄 수 있도록 하였다.
3. 스크롤시 국립국어원의 메인 컬러로 변경되어 가시성을 높이고자 하였다.

2. 호버시 왼쪽으로 늘어나며 각 아이콘에 맞는 제목이 드러나며, 영역에 호버할 경우에는 글씨의 색상이 변경된다.
